# hse-ml-course

This course is part of the master’s program Machine Learning and Data Analysis at HSE University (Higher School of Economics).

This repository started as an attempt to use the power of modern AI agents to turn our classic lecture slides (PDF and PPTX) into something more interactive and, we hope, more useful.  

The page with lectures and seminar notebooks is available [here](https://gvolsky.github.io/hse-ml-course/)
